## 🎮 ゲーム概要

主人公が犬や警察に追われながら、障害物を避け続けるサイドスクローリングアクションゲームです。  

### ゲームプレイ

| 操作 | アクション |
|---|---|
| `Space` | ジャンプ |
| ← / → | 左右移動 |
| クリック  | 進行 |
